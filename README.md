# PatternMystery

Godot 4.7.2용 CH1 첫 Vertical Slice입니다. 현재는 단일 클라이언트의 1차 포인트앤클릭 와이어프레임입니다. 중앙복도와 별관 철거구간만 화면 안 클릭 지점으로 구성하며, 다른 장소는 기존 자료 열람 형태를 유지합니다.

장소 이동 → 오브젝트 조사 → 개인 저널 등록 → 다른 장소에서 원문 재열람 구조를 유지합니다.

## 실행 및 테스트

Godot 4.7.2에서 `project.godot`을 열어 실행합니다. PowerShell에서는 설치된 실행 파일을 지정합니다.

```powershell
$godotExe = 'C:\Users\USER\Desktop\프로그램\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe'
& $godotExe --path .
& $godotExe --headless --path . --script res://tests/basic_loop_test.gd
```

명령은 프로젝트 루트에서 실행합니다. 다른 PC에서는 실행 파일 경로를 변경합니다. 테스트는 assertion이 활성화된 Godot 실행을 전제로 하며, 성공 시 `BASIC_LOOP_TEST_OK`를 출력합니다.

## 조작과 탐색

- 시작 대화는 화면 또는 계속 버튼을 클릭하여 진행합니다. 대화가 끝나면 조사할 수 있습니다.
- 중앙복도의 문·복도 영역을 클릭해 교무실, 시설자료실 또는 별관 철거구간으로 이동합니다. 특정 방문 순서는 요구하지 않습니다.
- 철거구간의 작업표(B-2), 자재, 벽체를 클릭합니다. 벽체 클릭은 확대 화면을 열며 저널에 등록하지 않습니다.
- 확대 화면에서 어두운 부분 → 철제 테두리를 조사하면 접근구 관찰이 기록됩니다. 이후 문틀·벽체·표식을 자유롭게 조사하거나 내부 공간을 관찰할 수 있습니다. 내부 관찰 시 두 번째 목격이 기록됩니다.
- 전체 현장 버튼으로 확대에서 복귀합니다. 중앙복도 복귀는 기존 별관 대기실 연결을 경유합니다. 별관 대기실도 기존 자료 열람 화면으로 방문 가능합니다.
- 상단 저널 버튼으로 오버레이를 열고 닫습니다. 원문·최초 발견 메타데이터를 재열람하며, 단서 연결이나 정답 안내는 없습니다.
- 대화와 저널 오버레이는 장소 조작을 막습니다. 자료실·교무실의 문서 조사 시에는 원문 열람 오버레이가 열립니다.
- 환경 안내문·작업 기록·현장 약도·작업표·자재는 짧은 대화로 표시되며 저널에 등록되지 않습니다.

중앙복도에서 교무실, 시설자료실, 별관 대기실로 이동할 수 있습니다. 별관 대기실은 벽체 철거 구간과 연결됩니다. 접근구 내부에는 진입하지 않습니다.

## 공개 정보

현재는 2026년이며 별관 정비 전 조사 중입니다. 벽체 철거 과정에서 옛 설비 접근구가 드러났습니다.

핵심 저널은 다음 6개입니다.

- 자료: 과거 별관 시설도면
- 자료: 시설 사용 종료·폐쇄 기록
- 자료: 2003년 박재영 실종사건 자료
- 자료: 2003년 교내 수색 기록
- 목격: 벽 뒤에서 드러난 설비 접근구
- 목격: 접근구 너머에 남아 있는 설비공간

행정상의 폐쇄와 현재 남아 있는 구조, 수색 기록의 확인 범위를 플레이어가 자유롭게 비교할 수 있습니다. 수색 기록을 거짓으로 단정하지 않으며 당시 접근 가능하고 안전한 확인 범위였을 가능성을 열어 둡니다. 원문은 발견 순서와 무관하게 동일하고, 재조사로 덮어쓰지 않습니다.

탐색·독해·재열람을 포함해 10~15분을 목표로 하지만 실제 소요 시간은 플레이테스트로 검증하지 않았습니다. 강제 대기나 특정 순서를 요구하지 않습니다.

## 구조와 검증

- `scripts/game_state.gd`: 고정 콘텐츠, 현재 위치, 이동·조사, 개인 저널, 콘텐츠 검증
- `scripts/main.gd`: 기존 단일 화면의 입력과 렌더링
- `scenes/Main.tscn`: 단일 루트 장면. `main.gd`가 장소 화면·대화·저널 오버레이를 생성합니다.
- `tests/basic_loop_test.gd`: 전체 self-test

테스트는 콘텐츠 검증, 실패 행동, 단서 없는 전 장소 이동, 환경 정보의 저널 미등록, 현장 먼저·기록 먼저 탐색, 6개 항목 등록, 중복 방지, 정렬·최초 발견 정보·원문 불변, 이동 후 UI 원문 재열람을 검사합니다. 시작 대화의 화면 좌표 클릭, 대화 중 입력 차단, 단계별 조사 공개·확대 복귀·저널 모달 동작도 검사합니다. 대부분은 버튼 신호 기반이며 시각적 레이아웃 및 사람의 플레이테스트를 대신하지 않습니다. 확대 여부와 관찰 단계는 UI에만 보관하며 GameState의 콘텐츠·저널 구조는 변경하지 않습니다.

## 이번 범위 밖

내부 전체 탐색, 이후 사건 전개와 실종 원인, 완료·정답 판정, 단서 기반 장소 해금, 범용 퀘스트·규칙·이벤트 시스템, 네트워크·저널 공유, 저장·불러오기, 최종 아트·오디오는 구현하지 않습니다.
